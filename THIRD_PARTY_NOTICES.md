## Dependency inventory

All direct and transitive package versions are pinned by package-lock.json. `docs/dependency-inventory.json` records installed package names, versions and declared licenses for review, including development-only tooling. Redistribution must retain applicable upstream notices. npm install may download dependencies; the running demo never fetches remote fonts, images or telemetry.
